# Rajasthan Plywood & Glass Home — GMB Posters

This repository stores manually prepared Google Business Profile (GMB) poster assets and Hindi captions for Rajasthan Plywood & Glass Home, Mandi 365 Head.

## Manual workflow
1. Request a new product poster and Hindi caption in ChatGPT.
2. Keep the poster vertical 4:5, photorealistic, bright/light premium, with restrained gold accents.
3. For Google Business Profile images, use only one short, accurate product heading. Do not include phone numbers, addresses, WhatsApp icons, RPGH branding, or long feature lists.
4. Save the image under `posters/YYYY-MM-DD-product-name.png` and the matching Hindi caption under `captions/YYYY-MM-DD-product-name.md`.
5. Review the image and caption before posting them to Google Business Profile. Saving files here does not publish them to Google.

## Folder conventions
- `posters/` — final PNG/JPG poster images.
- `captions/` — Hindi caption, local hashtags, and optional posting notes.

## Upload note
GitHub's Git Database API supports creating binary blobs with Base64 encoding. The connected GitHub integration exposes a blob operation with Base64 support, so image upload is technically supported, subject to payload/tool limits. The current workflow is manual; it does not automatically generate or publish posts.
